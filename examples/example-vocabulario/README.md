# Sequência: vocabulário em inglês

Estudo criado por **Marcelo Henrique Goncalves (@billmask)**. [Contribuição original](https://github.com/billmask/Recall.md/tree/7ea324a987e14d08ecc3501f0d2a125dc65ae061/example-vocabulario)

91 etapas, uma para cada lição de vocabulário listada em <https://www.learnenglish.com/english-vocabulary-page/>. Nenhuma página ligada foi aberta nem copiada. O texto de cada etapa é original: ordem de estudo, um exemplo e o link da fonte.

Ficaram de fora os links de menu, redes e rodapé (início, gramática, jogos, Pinterest, Twitter, sobre, privacidade e contato). Não são lições de vocabulário.

A grafia de estudo é a dos Estados Unidos. Onde o título da fonte usa colour, maths, films ou holiday, a etapa avisa o termo americano.

A partir da raiz do repositório Recall.md, copie a pasta para um novo destino antes de responder.

```bash
cp -a examples/example-vocabulario ~/vocabulario-ingles
cd ~/vocabulario-ingles
node /caminho/Recall.md/bin/recall.js unit list
node /caminho/Recall.md/bin/recall.js browser
```
